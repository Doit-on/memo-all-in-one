# Memo All In One - ระบบบันทึกข้อความและเอกสารองค์กรอัตโนมัติ

ระบบ Web Application สำหรับบริหารจัดการ ออกเลขที่ Running No. และจัดทำเอกสารองค์กรครบวงจร (Multi-Company Corporate Document Management System) 
สถาปัตยกรรม **100% Client-Side Serverless Single-File (`index.html`)** พร้อม Deploy บน GitHub Pages ทันที

---

## 🌟 จุดเด่นและคุณสมบัติใหม่ล่าสุด

1. **ระบบพิมพ์และเปิดดู PDF คุณภาพสูง (High-Fidelity PDF & Print Engine)**
   - **Isolated Iframe Printing**: ระบบพิมพ์และ "บันทึกเป็น PDF" ผ่าน Iframe แยกเอกเทศ คมชัดระดับเวกเตอร์ 100% ตัวหนังสือคมกริบ จัดระยะขอบ A4 (บน 2 ซม., ล่าง 1.5 ซม., ซ้าย 2.5 ซม., ขวา 2 ซม.) ถูกต้องตามแบบราชการและองค์กร
   - **ปุ่มเปิดดูแท็บใหม่ (Open Print Tab)**: สามารถกดเปิดดูเอกสาร A4 เต็มจอในแท็บใหม่ของเบราว์เซอร์ พร้อมแถบสั่งพิมพ์/บันทึก PDF ด้านบน
   - **Direct PDF Download**: ปรับปรุงตัวแปลง Canvas 2x CORS ให้ดาวน์โหลดไฟล์ PDF โดยตรงได้อย่างราบรื่น

2. **ระบบส่งออก Microsoft Word มาตรฐานเอกสารไทย (Compliant MS Word Export)**
   - **จัดขนาดโลโก้พอดี A4**: กำหนดขนาดโลโก้บริษัทให้อยู่ในสัดส่วนมาตรฐาน (65x65 px) ไม่ขยายตัวใหญ่ล้นหน้ากระดาษเหมือนเดิม
   - **จัดหน้าด้วย Table Layout สำหรับ Word**: ใช้โครงสร้างตาราง HTML ที่รองรับ Microsoft Word 100% หัวกระดาษ, วันที่, เลขที่, เรื่อง, ผู้รับ, ลายเซ็น และส่วนท้าย อยู่ในตำแหน่งที่ถูกต้องตามหลักสารบรรณ
   - **ย่อหน้าสารบรรณ 2.5 ซม.**: เนื้อหาทุกย่อหน้ามีการเคาะย่อหน้ามาตรฐาน 2.5 ซม. (Indentation) และแบบอักษร TH Sarabun New 16pt

3. **ลำดับขั้นตอนการทำงาน 3 สเต็ป (3-Step Workflow)**
   - **ขั้นตอนที่ 1: ออกเลขที่เอกสารล่วงหน้า** กดปุ่ม `🏷️ ออกเลขที่เอกสารล่วงหน้า (จองเลขทางการทันที)` เพื่อตัดเลข Running No. ทางการ ระบบจะแสดงเลขจริงบนหัวกระดาษพรีวิวสดทันที
   - **ขั้นตอนที่ 2: พิมพ์เนื้อหา & แนบไฟล์** กรอกชื่อเรื่อง ผู้รับ หน่วยงาน เนื้อหาใน Rich Editor และแนบไฟล์ประกอบ โดยไม่มีปัญหาข้อมูลหาย
   - **ขั้นตอนที่ 3: บันทึกยืนยันเนื้อหา** กดปุ่ม `💾 บันทึกยืนยันเนื้อหาเอกสาร (Finalize & Confirm)` เพื่อสรุปเอกสาร บันทึกสถานะ Published และซิงค์เข้า Google Sheet / Drive อัตโนมัติ

4. **ระบบแนบไฟล์และการบีบอัดรูปภาพอัจฉริยะ (Smart File Attachment)**
   - รองรับรูปภาพ (JPG, PNG, WebP) และเอกสาร (PDF, Word, Excel)
   - **บีบอัดรูปภาพอัตโนมัติผ่าน Canvas** ในเบราว์เซอร์: ลดขนาดรูปถ่าย 3-8 MB ให้เหลือเพียง **50 - 120 KB** คมชัด ชัดเจน ไม่เปลืองโควต้าความจำเบราว์เซอร์
   - แสดงรายชื่อในหัวข้อ **"สิ่งที่ส่งมาด้วย / เอกสารแนบ"** บนหน้ากระดาษ A4, Word และ PDF
   - มีหน้าต่างขยายดูภาพขนาดใหญ่ (Lightbox Preview) และปุ่มดาวน์โหลดไฟล์กลับลงเครื่อง

5. **เชื่อมต่อ Google Sheets & Google Drive กลาง (Apps Script Webhook & Central Registry)**
   - **Google Apps Script Web App Endpoint**: ฝังระบบ Webhook กลางพร้อมใช้งานทันที (`https://script.google.com/macros/s/AKfycbyBEoUBICy8Yh4vSaklQb6TbH-2gsyF8VFPml7NZHS1bLV7P8jNVGZ6w9v3g7fiU9v8/exec`)
   - **Google Sheets Memo List**: เชื่อมต่อสมุดทะเบียนคุมเอกสารออนไลน์โดยตรง (`https://docs.google.com/spreadsheets/d/1JpBrTgqbM0VbRTVPbDFwkY2__W1AkLSxtljKJs_4Xl8/edit?gid=0#gid=0`)
   - **In-App Google Sheet Viewer**: มีปุ่มและหน้าต่างดูทะเบียนคุม Google Sheets ในตัวโปรแกรม (ในเมนูด้านซ้าย, แถบด้านบน, หน้าคลังเอกสาร และหน้าสมุดทะเบียนคุม Running No.)
   - บันทึก Log ข้อมูลสำคัญ 15 คอลัมน์ลงใน Google Sheet อัตโนมัติ (วันเวลา, เลขที่เอกสาร, บริษัท, ประเภท, เรื่อง, ผู้รับ, ผู้ลงนาม, วันที่, จำนวนไฟล์แนบ, รายชื่อไฟล์แนบ, ลิงก์ Drive)
   - อัปโหลดไฟล์ PDF ตัวจริงและไฟล์แนบทุกไฟล์ไปยังโฟลเดอร์ Google Drive ของ `mayomco@gmail.com` พร้อมเปิดสิทธิ์แชร์ให้อ่านได้ทันที
   - มีปุ่ม **"ทดสอบการเชื่อมต่อ"** ในหน้าตั้งค่าเพื่อตรวจสอบความพร้อมใช้งานได้ทันที

6. **การตั้งชื่อไฟล์ส่งออกตามมาตรฐานองค์กรอัตโนมัติ (Standardized Corporate File Naming)**
   - ทุกครั้งที่ดาวน์โหลดหรือพิมพ์ PDF / Word ระบบจะตั้งชื่อไฟล์ตามรหัสย่อบริษัท + เรื่อง + วันที่ออกเอกสาร:
     - ไทยวัฒนาพานิช (`TWP`): เช่น `TWP ขออนุมัติ AI+2026-10-22.pdf`
     - ล๊อกแมท อินทิเกรชั่น (`LMI`): เช่น `LMI แจ้งประชุมบอร์ด+2026-10-22.doc`
     - เหนือน้ำแอร์ ปทุมธานี (`NNAP`): เช่น `NNAP หนังสือรับรองเงินเดือน+2026-10-22.pdf`

7. **ระบบกู้คืนลำดับเลขว่างและเริ่ม 001 ใหม่ (Sequence Gap Auto-Healing & Custom Numbering)**
   - **อนุญาตให้เริ่มเอกสารใหม่เป็นเลข 001 ได้เสมอ**: หากในระบบยังไม่มีเอกสารเลข 001 หรือเอกสาร 001 เคยถูกลบไป สามารถกดปุ่ม **"✨ เริ่มต้นใหม่ที่ 001"** เพื่อเปิดเอกสารเลข 001 ได้ทันที ไม่ถูกบังคับให้รันเลขต่อเนื่องข้ามไป
   - **ตรวจจับช่องว่างลำดับเลขอัตโนมัติ (Smart Sequence Gap Detection)**: เมื่อมีการลบเอกสารฉบับใดออกไป ระบบจะตรวจพบเลขที่ขาดหายไปและนำเลขนั้นกลับมาออกเป็นลำดับถัดไป เพื่อให้ชุดเลขที่เอกสารเรียงต่อเนื่องสมบูรณ์
   - **หน้าต่างกำหนดและแก้ไขเลขที่เอกสาร (`✏️ กำหนดเลขที่เอง / เริ่ม 001 / ซ่อมลำดับ`)**: มีปุ่มลัดเริ่ม 001, ซ่อมเลขว่าง, ช่องพิมพ์เลขที่กำหนดเอง พร้อมระบบตรวจสอบการซ้ำซ้อนแบบ Real-time
   - **ปุ่มตรวจสอบและซ่อมลำดับเลขว่าง (`🔄 ตรวจสอบและซ่อมลำดับเลขว่าง`)**: ในหน้าสมุดทะเบียนคุม Running No. (Audit Trail) สำหรับกดสั่งซิงค์ตัวนับให้ตรงกับเอกสารจริงในระบบได้ตลอดเวลา

8. **โครงสร้างไฟล์เดี่ยวสำหรับ Deploy GitHub (Single-File index.html)**
   - ไฟล์ `index.html` ถูก Bundle รวม CSS, JavaScript, โลโก้เวกเตอร์ และฟังก์ชันทั้งหมดไว้ในไฟล์เดียว
   - สามารถนำไฟล์ `index.html` ไปอัปโหลดบน GitHub Repository และเปิด **GitHub Pages** ได้ทันที 100% ไม่มีปัญหาพาธไฟล์หายหรือรูปไม่ขึ้น

9. **ระบบล็อกอินจำลองบรรยากาศ (Interactive Lamp Login Gateway)**
   - แอนิเมชันเปิด/ปิดไฟสไตล์ Glassmorphism
   - รหัสผ่าน Admin สำหรับเข้าใช้งานและตั้งค่า: **`memoadmin`**

## 🚀 วิธีการเปิดใช้งานบนเครื่องคอมพิวเตอร์ (Local)

1. ดับเบิลคลิกที่ไฟล์ **`Launch_Memo_All_In_One.bat`** (หรือดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ Chrome / Edge)
2. กระตุกสายโคมไฟเพื่อเปิดไฟ และกดปุ่มเข้าสู่ระบบ (รหัสผ่าน Admin: `memoadmin`)

---

## 🌐 วิธีการ Deploy ขึ้น GitHub Pages ฟรีใน 1 นาที

1. สร้าง Repository ใหม่บน GitHub เช่น `memo-all-in-one`
2. อัปโหลดไฟล์ **`index.html`** ไปไว้ที่ Root ของ Repository (หรือทั้งโฟลเดอร์)
3. ไปที่เมนู **Settings** ของ Repository บน GitHub > เลือกหัวข้อ **Pages**
4. ในส่วน **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** (หรือ master) / Folder: **/ (root)**
   - กดปุ่ม **Save**
5. รอประมาณ 1-2 นาที GitHub จะสร้างลิงก์เว็บไซต์ เช่น `https://username.github.io/memo-all-in-one/` พร้อมใช้งานได้ทันทีทั่วโลก
